# GuitarChordCLI

Aplikacja wyświetla gryf sześciostrunowej gitary i zaznacza na nim nuty akordów oraz skali.

## Skład projektu
- **CLITextTable** – biblioteka do rysowania tabeli.
- **GuitarChordCLI** – aplikacja konsolowa.

## Instalacja
Skompulować  na przykłąd w Visual Studio 2022

## Jak używać
- **Strzałki ← / →** – wybór „Root” (dźwięku podstawowego)
- **Klawisz M** – przełączanie między tonacją durową a molową
- **Klawisz S** – wyświetlanie lub ukrywanie skali na gryfie
